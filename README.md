# AI Website Analyzer - Универсальный анализатор сайтов

## Описание

Веб-приложение для комплексного анализа любых сайтов с использованием AI-агента. Введите URL любого сайта и получите детальный отчёт с рекомендациями по улучшению.

## Возможности

### 🔍 Универсальный анализ
- Работает с любым сайтом, который вы введёте
- Реальный анализ HTML-кода через CORS-прокси
- Автоматическая генерация рекомендаций на основе найденных проблем

### 📊 Четыре категории анализа

#### 1. Контент (Content)
- Проверка объёма текстового контента
- Анализ изображений и alt-текстов
- Проверка структуры заголовков (H1-H6)
- Наличие видеоконтента
- Количество ссылок и параграфов

#### 2. UX/UI
- Проверка адаптивной верстки (viewport)
- Наличие favicon
- Формы взаимодействия
- Навигация и ссылки
- Инлайн-стили

#### 3. SEO
- Title и meta description
- Open Graph и Twitter Card
- Canonical URL
- Структурированные данные (JSON-LD)
- Robots.txt и sitemap.xml
- Язык страницы

#### 4. Технические
- HTTPS/SSL
- Кодировка страницы
- Размер HTML
- Количество скриптов
- Наличие sitemap.xml

### 💡 Рекомендации
- Приоритизация проблем (критические, высокие, средние, низкие)
- Конкретные рекомендации по исправлению
- Ожидаемый эффект от внедрения
- Матрица приоритетов (влияние vs сложность)
- План внедрения по неделям

## Как это работает

1. **Ввод URL** - пользователь вводит адрес любого сайта
2. **Загрузка HTML** - приложение получает HTML через CORS-прокси (allorigins.win, corsproxy.io)
3. **Парсинг** - анализ HTML-структуры с помощью DOMParser
4. **Проверки** - выполнение 30+ проверок по четырём категориям
5. **Оценка** - расчёт баллов (0-100) для каждой категории
6. **Рекомендации** - генерация списка проблем с решениями
7. **Отчёт** - отображение результатов с визуализацией

## Технологии

- **React 18** + TypeScript
- **Vite** - сборка
- **Tailwind CSS** - стилизация
- **DOMParser** - парсинг HTML
- **CORS Proxies** - обход CORS-ограничений

## Использование

1. Откройте приложение
2. Введите URL сайта (например: `example.com` или `https://example.com`)
3. Нажмите "Начать анализ"
4. Дождитесь завершения анализа (10-30 секунд)
5. Изучите результаты и рекомендации

## Примеры сайтов для анализа

- `nic-conf.ru` - сайт конференции
- `habr.com` - технологический блог
- `ted.com` - образовательная платформа
- `python.org` - официальный сайт Python
- Любой другой публичный сайт

## Ограничения

- Анализ только публично доступных страниц
- Зависимость от CORS-прокси (может быть недоступен)
- Анализ только главной страницы (не всего сайта)
- Не проверяется JavaScript-рендеринг (SPA)
